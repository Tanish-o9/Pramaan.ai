### FEATURE 1 – pgvector 1:N Fast Vector Search
* **What Exists:** In-memory loop loading all enrolled student embeddings and computing Euclidean norm in Python/numpy.
* **What Changes:**
  - PostgreSQL extension `vector`.
  - Dedicated `student_embeddings` table storing `vector(128)` for face and `vector(256)` for voice.
  - Multi-embedding support (e.g., student with glasses, low light, different days).
  - HNSW indexing: `<->` (L2 distance) for face, `<=>` (Cosine distance) for voice.
  - Subject-scoped SQL RPC (`match_face_embeddings`, `match_voice_embeddings`) with Top-K, distance cutoff, and margin check (`second_best - best >= margin_threshold`) to reject ambiguous matches.
  - Benchmark script (`scripts/benchmark_pgvector.py`) & documentation (`docs/PGVECTOR.md`).
  - Feature flag: `ENABLE_PGVECTOR = True` with automatic in-memory fallback.
* **Database Migration (SQL):**
  ```sql
  create extension if not exists vector;

  create table if not exists student_embeddings (
    id bigint generated by default as identity primary key,
    student_id bigint references students(student_id) on delete cascade,
    modality text not null check (modality in ('face', 'voice')),
    embedding vector(128),
    voice_embedding vector(256),
    quality float default 1.0,
    source text default 'web_registration',
    created_at timestamptz default now()
  );

  create index if not exists idx_student_embeddings_face_hnsw 
    on student_embeddings using hnsw (embedding vector_l2_ops);

  create index if not exists idx_student_embeddings_voice_hnsw 
    on student_embeddings using hnsw (voice_embedding vector_cosine_ops);
  ```
* **Risks & Mitigation:** pgvector not enabled on local dev Postgres -> Graceful fallback to numpy L2 norm in Python service layer.

### FEATURE 2 – Unknown Face Gallery & Active Learning
* **What Exists:** Detected faces with distance > 0.60 are discarded with no audit or learning.
* **What Changes:**
  - Table `unknown_faces` storing session ID, subject ID, face crop thumbnail (JPEG small bytes/base64), vector embedding, quality metrics (Laplacian blur, brightness, bounding box area).
  - Faculty Review Gallery: Cluster unknown faces by cosine similarity, allow faculty to tag to a student or dismiss.
  - Safety Gates: Quality score check (>0.7), duplicate check, max 10 embeddings per student cap, rejection if >0.45 distance from existing centroid, audit log.
  - Auto-purge retention job (e.g. delete after 30 days).
  - Benchmark script: Pre- vs. Post-enrollment recognition recall script.

---

### FEATURE 3 – Mid-Class Random Pulse Check
* **What Exists:** Attendance is taken once at the start of class; proxy students can leave immediately after check-in.
* **What Changes:**
  - Faculty initiates "Pulse Check" during active lecture (random 1-5 students or 10%).
  - Real-time notification/WebSocket/polling prompt on student dashboard.
  - 2-minute countdown for student to perform face + EAR liveness check.
  - Status logged in `pulse_checks` (passed, failed, missed).
  - Missed/failed pulse checks degrade session Trust Score by -25 pts and trigger faculty review flag.
  - Fair seed-based pseudo-random picker avoiding re-sampling same student in a single lecture.

---

### FEATURE 4 – Biometric Model Monitoring & Drift Dashboard
* **What Exists:** Basic `/metrics` endpoint with counters.
* **What Changes:**
  - Table `match_events` capturing metadata of every biometric inference: modality, distance, margin, liveness EAR, image quality, latency ms, outcome, model version.
  - Faculty/Admin Recharts dashboard: Daily average confidence, rejection rate, latency p50/p95, low-quality frame ratio.
  - Population Stability Index (PSI) / Kolmogorov-Smirnov drift detection over 7-day sliding window.
  - Alert banner when drift exceeds threshold (PSI > 0.25).
  - Docs: `docs/MONITORING.md`.

---

### FEATURE 5 – Academic Condonation Workflow
* **What Exists:** Rule-based bunk calculator with static 75% target and excused classes.
* **What Changes:**
  - Formal multi-step condonation application: reason, valid medical/OD certificate PDF (size/type validated), subject selection.
  - Hierarchy roles: Faculty -> Head of Department (HoD) -> Dean.
  - Institution-configurable rules (e.g. Theory 75%, Lab 80%, maximum 10% condonable).
  - Separate `condoned_percentage` calculation (leaves raw physical attendance logs untouched for legal compliance).
  - Admin audit report: Turnaround time, approval ratios.

---

### FEATURE 6 – University Event & Seminar Mode
* **What Exists:** Only semester regular classes exist.
* **What Changes:**
  - Table `events`: title, date, venue, capacity, target department.
  - Entry gate: Dedicated fast kiosk / QR entry with anti-duplicate prevention and live real-time headcount counter.
  - Auto-generation of tamper-evident PDF Certificates with ReportLab, containing unique UUID certificate ID and verification QR.
  - Public verification route: `/verify/{certificate_id}` displaying authenticated recipient, event name, and date.

---

### FEATURE 7 – Tamper-Evident Digital Student ID Card
* **What Exists:** Student credentials exist as database records; no physical/digital student card.
* **What Changes:**
  - Digital ID view in Student Portal with university branding, student photo (if opted in), roll number, and department.
  - Dynamic QR containing signed HMAC-SHA256 / short-lived JWT that rotates every 60 seconds (prevents screenshot forwarding).
  - Security/Faculty Scanner Mode: Camera scanner verifying cryptographic signature and showing real-time enrollment validity.
  - Instant administrative revocation toggle.

---

### FEATURE 8 – Classroom Seat Map Attendance
* **What Exists:** Attendance is a flat list without spatial awareness.
* **What Changes:**
  - Interactive classroom grid configuration (rows, columns, aisles, broken/empty seats).
  - Seat assignment matrix (manual or CSV batch assign).
  - Spatial mapping: Detected face bounding boxes projected onto seat grid using homography/perspective transform.
  - Flagging: "Sitting in unassigned seat" soft warning without marking student absent.
  - Docs: `docs/SEATMAP.md` covering perspective limits and 4-corner calibration guide.

---

### FEATURE 9 – Teacher Voice Command Roll-Call
* **What Exists:** Manual mouse clicking or photo upload.
* **What Changes:**
  - Push-to-talk microphone button on attendance screen.
  - Voice transcription via local Whisper or Web Speech API (English + Hindi/Hinglish: *"Mark all present except roll 12 and 24"* / *"बारह और पंद्रह एब्सेंट"*).
  - Pydantic constrained schema parser with strict confirmation dialog: *"Mark 58 present, 2 absent: 21CS012, 21CS024. Confirm?"*.
  - Full audit logging of original audio transcript and applied changes.

---

### FEATURE 10 – University Calendar & Timetable Sync (iCalendar / ICS)
* **What Exists:** Dynamic join codes only; no schedule awareness.
* **What Changes:**
  - Timetable schedule engine with recurring lecture slots, holidays, and room allocations.
  - Private, tokenized feed URL (`/api/calendar/feed/{token}.ics`) adhering to RFC 5545 with `Asia/Kolkata` timezone.
  - One-click subscription for Google Calendar, Apple Calendar, and Microsoft Outlook.
  - Instant sync when faculty reschedules or cancels a class session.

---

### FEATURE 11 – Department Head (HoD) Governance Dashboard
* **What Exists:** Single teacher dashboard and student dashboard.
* **What Changes:**
  - New RBAC role: `hod` (Head of Department) with department-scoped access.
  - Cross-section comparative metrics: attendance across sections A/B/C, faculty lecture completion rate, chronic defaulter list (<65%).
  - Condonation & dispute approval queue.
  - One-click "Download Official Defaulter Notice" formatted PDF.
  - Strict department isolation (e.g. CSE HoD cannot view Mechanical Engineering records).

---

### FEATURE 12 – Institutional Announcements & Notice Board
* **What Exists:** No direct notification/broadcast channel.
* **What Changes:**
  - Scoped announcements: Subject-level (Faculty), Department-level (HoD), Institution-level (Admin).
  - Rich text sanitization (strips malicious scripts), pinned notices, expiry dates.
  - Student notification bell with unread badge counter.
  - Aggregated faculty read receipts (percentage of enrolled students who viewed notice).
